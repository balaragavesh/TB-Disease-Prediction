# TB-Disease-Prediction
## Overview
This project implements a Convolutional Neural Network (CNN) to predict Tuberculosis (TB) from chest X-ray images. The model automates TB detection, aiding in early diagnosis and improving screening efficiency.

## Features
- Deep learning-based TB detection using CNN.
- Trained on a labeled dataset of chest X-ray images.
- Provides a probability score indicating TB presence.

## Dataset
- The model is trained on a labeled dataset of chest X-rays containing TB-positive and TB-negative samples.

## Model Architecture
- CNN with multiple convolutional layers.
- Batch normalization and dropout for better generalization.
- Trained using TensorFlow
